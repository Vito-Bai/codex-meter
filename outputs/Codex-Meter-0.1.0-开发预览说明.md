# Codex Meter 0.1.0 开发预览

这是首个可运行的 macOS 菜单栏开发预览版。

## 已实现

- 从 Codex App Server 读取当前套餐、额度窗口、剩余百分比、重置时间和重置券。
- 从本地 Codex rollout 聚合逐轮 token；默认只提取用户 Prompt 的短标题，不读取回答、代码或工具输出，标题读取可在设置中关闭。
- 展示输入、缓存输入、非缓存输入、输出、推理输出和本轮总 token。
- 菜单栏额度状态与轮次完成临时反馈。
- 菜单栏使用官方 Codex 图标 + 状态环 + 百分比的紧凑标识。
- 菜单栏拥挤时可使用全局快捷键 `⌥⌘C` 打开用量复盘；Dock 入口默认关闭。
- 最近轮次、个人中位数基线与异常倍数。
- 独立用量复盘窗口：逐轮堆叠图、缓存命中、工具循环、高消耗榜单。
- 每轮反馈时长、历史记录与高消耗提醒设置。

## 安装

1. 打开 DMG。
2. 将 `Codex Meter.app` 拖入 Applications。
3. 首次启动后，菜单栏会出现额度百分比。

当前版本使用本机开发签名，没有经过 Apple 公证。如果 macOS 阻止首次打开，可在“系统设置 → 隐私与安全性”中选择仍要打开。正式发布版会使用 Developer ID 签名与公证。

## 当前边界

- 逐轮数据目前来自本地 Codex 会话元数据；未在本机留下 rollout 的远程任务可能只有总额度变化，没有逐轮明细。
- Token 数是模型处理量，不等于套餐额度扣减值，不能固定比例换算。
- Prompt 标题隐私开关已持久化；其它设置项仍可能在重启后恢复默认值。
- 当前最低支持 macOS 14。

## 隐私

应用不读取对话正文，不保存鉴权 token，不上传用量历史。所有逐轮分析均在本机完成。
